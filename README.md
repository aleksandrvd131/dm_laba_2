# Лабораторная работа №2 по Дискретной математике

Реализация алгоритмов теории чисел и полей Галуа:
* **Задача 13**: Конечное поле $GF(256)$ ($GF(2^8)$), нахождение всех 30 неприводимых многочленов степени 8 над $GF(2)$, сложение, умножение и нахождение обратного элемента по модулю $283$ ($x^8 + x^4 + x^3 + x + 1$, полином стандарта AES).
* **Задача 14**: Классический и расширенный алгоритм Евклида, соотношение Безу ($a \cdot x + b \cdot y = \gcd(a, b)$), быстрое бинарное возведение в степень, поиск обратного элемента по модулю 67 алгоритмом Евклида и малой теоремой Ферма ($a^{65} \pmod{67}$).
* **Задача 15**: Теоретико-числовые функции:
  - Функция Мёбиуса $\mu(n)$
  - Количество натуральных делителей $d(n)$ ($\tau(n)$)
  - Функция Эйлера $\varphi(n)$
  - Сумма натуральных делителей $\sigma(n)$
  - Количество различных простых делителей $\omega(n)$
  - Функция Кармайкла $\lambda(n)$
  - Функция Мангольдта $\Lambda(n)$

---

## Структура проекта

- `gf256.h` / `gf256.c` — арифметические операции в поле $GF(256)$: ввод, вывод многочленов, деление с остатком, проверка неприводимости, поиск модулей, сложение, умножение, возведение в степень, обращение.
- `Euclid.h` / `Euclid.c` — вычисление НОД и расширенный алгоритм Евклида с коэффициентами Безу.
- `binpow.h` / `binpow.c` — быстрое возведение в степень за $O(\log k)$ по модулю.
- `numbers.h` / `numbers.c` — вычисление теоретико-числовых функций.
- `main.c` — интерактивное меню выбора задачи (13, 14 или 15).

---

## Компиляция (без Makefile)

Для компиляции проекта используется `gcc` с линковкой математической библиотеки `-lm`:

```bash
gcc -Wall -Wextra *.c -lm -o lab2
```
